# NOW

## Где мы сейчас
У Hubsty есть рабочий MVP в Telegram Mini App формате.

Работает:
- вход через Telegram
- выбор роли: кандидат / работодатель
- анкета кандидата
- анкета работодателя
- создание вакансии
- просмотр вакансий кандидатом
- отклик на вакансию
- просмотр статусов откликов
- кабинет работодателя
- просмотр кандидатов по вакансии
- смена статусов по кандидатам
- открытие контактов после нужного этапа
- прямые действия: позвонить / написать в Telegram

## Что уже является ядром продукта
Это важно сохранить и не ломать:
- fit score / совпадение
- блок "почему подходит"
- reliability / надежность
- понятные статусы
- следующий шаг для кандидата и работодателя
- короткий Telegram-first путь до контакта

## Что уже поняли
Главная ценность Hubsty:
не быть еще одной доской вакансий, а быстро доводить до контакта между кандидатом и работодателем.

Сильные стороны текущего MVP:
- понятный flow
- короткий путь
- Telegram как основной интерфейс
- локальный HoReCa use case
- понятные статусы и действия

## Что не делаем резко
Пока не ломаем:
- текущие сущности
- текущие роли
- текущую логику вакансий и откликов
- текущую надежность
- текущий fit score

Любые новые идеи добавляем поверх существующего ядра аккуратно.
