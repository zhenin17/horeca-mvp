# HoReCa MVP

## Стартовые роли
- официант
- бармен
- хостес
- бариста

## Скоринг
Двухслойный:
1. скор профиля кандидата
2. скор совпадения с вакансией

## Надежность
Гибрид:
- единый рейтинг 0–100
- отдельные показатели:
  - доходимость
  - выходы
  - завершение смен
  - повторные приглашения

## Контуры MVP
- candidate mini app
- employer interface
- admin panel
- telegram bot
- backend API
- PostgreSQL
