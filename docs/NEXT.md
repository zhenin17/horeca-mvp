# NEXT

## Следующий продуктовый этап

### 1. Смены / подработка
Добавить поверх текущего продукта новый слой:
- постоянная работа
- подработка
- смена

Важно:
не ломать текущую vacancy-логику, а расширить ее.

### 2. Reliability 2.0
Сохранить текущую надежность и потом аккуратно усилить ее.

Что потенциально добавить позже:
- фактические выходы
- невыходы
- повторные приглашения
- завершенные смены
- признак "работал раньше"

Но текущую reliability-логику не выкидывать.

### 3. Свои кандидаты / повторный вызов
Для работодателя позже может появиться:
- свой кандидат
- уже работал у меня
- позвать снова
- повторный выход на смену

### 4. Каналы как источник трафика
Не делать отдельный новый продукт.
Использовать каналы как distribution layer:
- пост в канале
- deep link
- переход
